PORTFOLIO EDITING GUIDE
=======================

This site is intentionally plain HTML + CSS so it stays easy to change later.
You do NOT need a site builder or framework to edit the wording.

MAIN FILES
----------
index.html
  Homepage copy and project cards.

projects-induction-soldering.html
  Full induction soldering case study.

projects-ace.html
  Full Automated Court Enhancer (ACE) case study.
  The main editable copy blocks are marked with comments such as:
      <!-- EDITABLE COPY: ACE HERO -->
      <!-- EDITABLE COPY: ACE SECTION 1 -->

styles.css
  Site-wide colors, spacing, type, image layout, mobile behavior, etc.

HOW TO CHANGE TEXT
------------------
1. Make a backup copy of the site folder.
2. Open the relevant .html file in VS Code, Notepad++, or another text editor.
3. Use Ctrl+F to find the sentence or heading exactly as it appears on the website.
4. Edit only the text between HTML tags.

Example:
    <h2>The final robot was not perfect, but the core cleaning idea worked.</h2>

You can change the sentence without changing <h2> or </h2>.

HOW TO CHANGE AN IMAGE
----------------------
1. Put the new image in the appropriate folder under public/images/.
2. Find the <img ... src="..."> line in the relevant HTML file.
3. Replace only the file path inside src="...".

SITE SCALE / RESPONSIVE SIZING
------------------------------
The final sizing adjustments are grouped at the bottom of styles.css under:
    /* v0.21 compact responsive scale pass */

That block intentionally overrides earlier values without removing the older design history.
Key controls there include the homepage h1/h2 sizes, hero image height, section spacing,
case-study image sizes, and the tablet/mobile media queries.
